# Nua Aqua - Premium Hydration Experience

Nua Aqua is a modern, high-performance web application showcasing a premium water brand. Built with a focus on visual excellence and smooth user experience, it features detailed product showcases, business opportunity portals for franchising and distribution, and an elegant corporate presence.

## 🚀 Live Demo
[www.nuaaqua.com](https://www.nuaaqua.com/)

## 📂 GitHub Repository
[Prakashsuriya/Nua-20Aqua](https://github.com/Prakashsuriya/Nua-20Aqua.git)

## 🛠 Tech Stack

### Frontend
- **Framework**: React 18 with Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS for responsive and modern UI
- **Animations**: Framer Motion for premium micro-interactions
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Forms**: React Hook Form with Zod validation
- **State Management**: TanStack React Query
- **UI Components**: Radix UI primitives

### Backend
- **Server**: Express (Node.js)
- **Validation**: Zod

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [pnpm](https://pnpm.io/) (preferred package manager)

## ⚙️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Prakashsuriya/Nua-20Aqua.git
   cd Nua-20Aqua
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   # or
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to see the result.

4. **Build for production**
   ```bash
   npm run build
   ```

## 🏗 Project Structure

- `client/`: React frontend source code
  - `components/`: Reusable UI components (Header, Footer, etc.)
  - `pages/`: Individual page components (Home, Products, Franchise, etc.)
- `public/`: Static assets (Images, Logos)
- `server/`: Express backend logic
